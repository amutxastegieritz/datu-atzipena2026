# Lurraldebus

* **Erakundea:** Gipuzkoako Foru Aldundia (Gipuzkoa Irekia atariaren bidez).
* **Url:** [opendata.gipuzkoa.eus](https://opendata.gipuzkoa.eus)
* **Datua:** Lurraldebusen autobus-lineen ibilbideak, geralekuen kokapen zehatza, kokapenean pasako diren hurrengo autobusak eta ordutegiak.
* **Formatua:** `.csv` fitxategia, `.xml` edo **GTFS** (Garraio publikorako formatu estandarra).
